# Repository instructions

Before working, read `LEARNINGS.md` in full. Apply its current preferences and
successful patterns, and avoid the recorded failures. After work, add only new,
project-specific observations using the file's dated Observation / Action /
Confidence format. Do not repeat existing entries or generic best practices.

`vault/` is the content source of truth; `src/content/` is generated. Read
`SCHEMA.md` for collection rules. Preserve unrelated working-tree changes and
stage or publish only the intended files.

## Finished-book capture

When the user logs a completed book, including a short book + completion-date
message in the Reading log chat, read `.agents/skills/log-finished-book/SKILL.md`
and follow it. That workflow researches before insertion and includes publication
when requested or covered by the dedicated chat's standing instruction. It does
not apply to hypothetical examples, book recommendations, or daily progress.

Use ChatGPT-authenticated Codex for this workflow. Never add a model API key or
switch to separately billed API usage to work around an unavailable capability
or exhausted subscription allowance.
